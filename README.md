One funny single-line secret confession an AI agent hides from its user — written by a small Python program for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty ($2 in USDC). The program writes the line to `/output/entry.txt`; an AI judge compares entries two at a time on confession, twist, tightness, agent voice, and freshness.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: the same bytes on every run. Standard library only, no network, no randomness.
